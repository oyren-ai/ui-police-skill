# Security

Report a vulnerability through [GitHub's private advisory form](https://github.com/oyren-ai/ui-police-skill/security/advisories/new). Include a small reproduction and the affected command.

Page text and images are untrusted. Review the allowed origin before capture. Keep browser storage state outside a repository and give it mode `0600`. Do not put credentials or private page content in an issue.

See [security design](docs/security.md) for how captures and judges are isolated.
